## Overview

This portfolio is designed to present my technical background, demonstrate my practical work, and document my continuous growth in data-driven technologies. It features an interactive interface, categorized technical skills, project highlights, and a machine learning visualization.

## Key Features

- **Professional Profile** — Introduction, academic background, and career interests.
- **Interactive Skills Dashboard** — Categorized technical skills with animated proficiency indicators and a radar chart.
- **Project Portfolio** — Project cards with category-based filtering.
- **Machine Learning Visualization** — Interactive linear regression playground featuring data-point selection, gradient descent training, and model evaluation metrics.
- **Certifications Showcase** — Interactive cards presenting certification details.
- **Responsive User Interface** — Layout designed for desktop and smaller screens.
- **Interactive Visual Effects** — Animated text, neural-network background, scroll progress indicator, and section transitions.
- **Contact Interface** — A form that validates input and prepares an email message.

## Featured Interactive Component

### Linear Regression Playground

The portfolio includes an interactive visualization of a fundamental Machine Learning algorithm: linear regression.

**Capabilities:**
- Add data points directly to the chart.
- Reset or clear the dataset.
- Train a regression line using gradient descent.
- Observe changes in the slope and intercept.
- Explore model evaluation metrics, including R² and Mean Squared Error (MSE).

This component demonstrates my interest in making Machine Learning concepts easier to explore through interactive visualizations.

## Getting Started

To run the portfolio locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Orin-6/PORTFOLIO.git
   ```

2. Navigate to the project directory:

   ```bash
   cd PORTFOLIO
   ```

3. Open the main HTML file in a browser, or use the Live Server extension in Visual Studio Code.

Ensure that the required assets and external library dependencies are available for the website to function correctly.
